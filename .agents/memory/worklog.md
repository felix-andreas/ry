# Work log

This file holds one line per autonomous work cycle, newest last.

It is the one file in `.agents/memory/` that is deliberately chronological. The timeless rule that
governs `MEMORY.md`, `backlog.md` and `decisions/` does not apply here, so do not turn it into a
knowledge document: a durable fact belongs in those files, and this file only records what happened.

Write an entry as `- YYYY-MM-DD HH:MM: what landed. Loose end, if any.` on one line of at most 400
bytes (`python3 tools/memory.py check` enforces it). A cycle that found nothing worth doing says so,
because an empty line is more useful than invented work.
