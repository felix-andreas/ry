Each program runs as plain R on GNU R, as the same plain R on ry, and typed in
[strict mode](/tutorial/fully-typed#strict-mode) on ry. All three compute the same result.

<BenchmarkTable />

Recursion and loops gain the most, while vectorized builtins already run in C on GNU R. Types add
a second gain: a typed function in strict mode compiles to native code before its first call and
works on native numbers, strings and lists, so `closures`, `report` and `expr_tree` run between 60
and 120 times faster typed than on GNU R. Whole-vector arithmetic (`vector_arith`) gains little,
because each operation still writes a new vector, and the typed functions over `Result` and
dictionaries (`validate`) run about twice as fast as untyped code.

## How it was measured

Each program times its own work with the harness above, so startup and the static check are left
out. The harness runs once to warm up, then three times, and keeps the fastest run.

`just bench-why --write` runs every program twice per engine, alternating engines, and stores the
fastest time and the largest memory peak in `tools/bench/why/results.json`, which every table on
this site reads.
