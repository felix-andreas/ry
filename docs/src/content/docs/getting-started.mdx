ry is a toolchain for R, written in Rust. It checks, formats and runs the R code you already have,
and it adds static types and its own data types on top. Plain R stays valid, and the checker never
runs your code.

## What ry does

- **Check**: unresolved names, syntax errors, lints and, once you switch typing on, type errors.
- **Format**: `ry fmt`, one style for every file.
- **Edit**: hover, completion, rename, go to definition and quick fixes in any LSP editor.
- **Load**: `ry load` and the `ry run` console reload a package after an edit in milliseconds.
- **Run**: `ry run` runs R on ry's own runtime, with a JIT, records, tagged unions and a typed
  table.

ry is in beta. The checker, formatter, language server and package loader are ready for daily use,
and diagnostic codes, `ry.toml` keys and the JSON output are stable. ry's runtime is incomplete:
code that needs something it lacks stops with an error that names it, and `ry R` runs the same code
on GNU R.
