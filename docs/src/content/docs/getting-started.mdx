ry is a toolchain for R, written in Rust. It checks, formats and runs the R code you have, and adds
static types and its own data types on top. You adopt it in four steps and can stop after any of
them:

| Step | You add | ry reports or runs | Runs on GNU R |
| --- | --- | --- | --- |
| [1. Check](/tutorial/check) | nothing | unresolved names, syntax errors, lints; formats | yes |
| [2. Type](/tutorial/types) | `typing = true`, `#:` comments | type errors | yes |
| [3. Run](/tutorial/runtime) | `ry run` | faster R, inline types, records, tagged unions | no |
| [4. Go fully typed](/tutorial/fully-typed) | `strict = true` | an error for every value without a known type | no |

## Check

With no configuration, ry resolves every name by R's scoping rules:

```r
net_price <- function(price, rate) {
  price * (1 - ratee)
}
```

```text ry check
unresolved
  ! I could not resolve `ratee` in this package, its imports, or builtins. Did you mean `rate`?
```

## Type

With `typing = true`, ry infers types from use. A `#:` comment pins a contract, and the file stays
plain R:

```r
#: fn(price: double, rate: double) -> double
net_price <- function(price, rate) {
  price * (1 - rate)
}

net_price(100, "0.2")
```

```text ry check typing
type-mismatch
  x expected `double`, found `character`
```

## Run

`ry run` runs R on ry's own runtime. Untyped R is faster than GNU R where the JIT applies and slower
on call-heavy code, so the two benchmarks are shown side by side:

The real-world workloads are call-heavy: most time goes to calling small closures, dispatching S3
and S4 methods, signaling conditions and building strings and lists, which the JIT does not
speed up yet. The kernels are tight loops and vector code. Seconds per kernel, the same plain R on
GNU R and on ry, and typed in strict mode on ry:

Typed functions over numbers, records and `match` compile to native code, which is where the large
gains are. [Benchmarks](/benchmarks) has every program, the real-world table and the method.

## Model data

ry's records and tagged unions run on its runtime, and `match` must handle every case:

```r
alias Payment =
  | :Paid(amount: double)
  | :Refunded(amount: double)
  | :Pending

balance <- function(payment: Payment) -> double {
  match (payment) {
    :Paid(amount = a) => a
    :Refunded(amount = a) => -a
  }
}
```

```text ry check typing
non-exhaustive-match
  x this `match` does not handle `:Pending`: add an arm for it, or a catch-all `_ => ...` arm
```

Records, tags, `I64`, `Str`, `List` and the standard library together form typed ry, a small
language with sound types that never touches an R data type. [Typed ry](/reference/language) is a
one-page tour.

## Status

ry is in beta. The checker, formatter, language server and package loader are ready for daily use,
and diagnostic codes, `ry.toml` keys and the JSON output are stable. ry's runtime is incomplete:
code that needs something it lacks stops with an error that names it, and `ry R` runs the same code
on GNU R.
