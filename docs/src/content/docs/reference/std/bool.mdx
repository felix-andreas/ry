Booleans are R's `TRUE` and `FALSE`, never `NA`. R's operators already cover most of this module;
its functions exist so that a boolean step can be passed by name, as in `List.walk(flags,
Bool.true, Bool.and)`, and so that code written against Roc's names reads the same.

| Function | Summary |
| --- | --- |
| [`Bool.true`](#booltrue) | `TRUE`, as Roc spells it. |
| [`Bool.false`](#boolfalse) | `FALSE`. |
| [`Bool.and`](#booland) | Whether both are `TRUE`. |
| [`Bool.or`](#boolor) | Whether either is `TRUE`. |

| [`Bool.is_eq`](#boolis_eq) | Whether two values are equal by `identical()`, the library's equality. |

Whether two values are equal by `identical()`, the library's equality. An integer and a double
are never identical, so `Bool.is_eq(1L, 1)` is `FALSE`, and a dictionary or set compares without
regard to order.

```r ry run runtime=ry dput
Bool.is_eq(Set.from_list(list(1L, 2L)), Set.from_list(list(2L, 1L)))
#> TRUE
```

[Source](https://github.com/felix-andreas/ry/blob/main/types/std.Rtypes#L1783)
