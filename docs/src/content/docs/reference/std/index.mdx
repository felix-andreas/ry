ry's standard library is the `std` namespace. With the prelude on, the default, every function is also in scope by its bare name, such as `List.map`; with `[check] prelude = false` it is reachable only as `std::List.map`. The [standard library guide](/reference/standard-library/) covers the conventions the modules share.
