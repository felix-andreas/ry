A result is `:Ok(value)` or `:Err(error)`, typed `Result<T, E>`. The alias is built in, so every
annotation can use it.

```
@alias Result<T, E> {:Ok(T) | :Err(E)}
```

</TabItem>

Chains a step that can fail: `f` gets the `:Ok` value and returns the next result. The error type
of the chain joins both, so a step can fail with a reason of its own.

```r ry run runtime=ry dput
Result.and_then(Str.to_i64("-3"), function(n) if (n > 0) :Ok(n) else :Err(:NotPositive))
#> :Err(:NotPositive)
```
