Functions over `List<T>`, ry's ordered sequence of values of one type. `[1, 2, 3]` builds a
list, and `List.from_r` converts an R vector or list. A function whose result items come from a
callback, such as `List.map`, requires them to be ry values (the
[`item` constraint](/reference/type-system/#constraints)), so `List.map([1, 2], \(x) list(x))` is
a type error.

Converts an R vector or list into a `List`, checking every item: it refuses `NA`, a classed
object and a ragged list, and drops names. A `double` vector becomes a `List<F64>`, an
`integer` vector a `List<I32>`, a `logical` vector a `List<Bool>`, a `character` vector a
`List<Str>` and a `raw` vector a `List<U8>`.

```r ry run runtime=ry dput
List.from_r(c(3, 1, 2))
#> [3, 1, 2]
```

Converts a `List` into the R vector it shares a representation with. A list of ry integers
becomes an `integer` vector when every item fits in 32 bits and a `double` vector otherwise. A
`List<F64>`, `List<Bool>` or `List<Str>` already passes to R code as a vector without this call.

```r ry run runtime=ry dput
List.to_r([3i64, 1i64])
#> c(3L, 1L)
```

## `List.range`

<Tabs syncKey="annotation-style">


</TabItem>
<TabItem label="Comments">

```r
#: <T: int> fn(start: T, end: T) -> List<T>
List.range <- function(start, end)
```

</TabItem>
</Tabs>

The integers from `start` up to and including `end`, or an empty list when `end` is smaller.
Unlike R's `:`, it never counts down.

Both `List.range` and `List.repeat` stop with an error when the list would hold more than
2,147,483,647 elements, the longest vector an R integer index reaches.

```r ry run runtime=ry dput
List.range(2, 5)
#> [2i64, 3i64, 4i64, 5i64]
List.range(3, 1)
#> []
```
