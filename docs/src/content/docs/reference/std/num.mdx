Functions over single numbers, `integer` or `double`, and eight constants (`Num.pi`, `Num.tau`,
`Num.e`, `Num.infinity` and the integer and double limits). A checked operation returns the
failure as a tag where R would return `NA`, `NaN` or `Inf` with a warning; its unchecked twin
(`Num.add` beside `Num.add_checked`) stops with an error in that case. A `NaN` result, such as
`Inf - Inf` or `Num.sin(Inf)`, is `:Err(:Undefined)` from a checked operation and an error from
any other. The bit operations take integers as 32-bit two's complement.
