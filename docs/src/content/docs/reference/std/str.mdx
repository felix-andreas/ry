Decodes UTF-16 code units, or `:Err(:BadUtf16)` for an unpaired surrogate or a zero unit, which
an R string cannot hold. A number outside 0 to 65535 is an error.

```r ry run runtime=ry dput
Str.from_utf16(list(104L, 55357L))
#> :Err(:BadUtf16)
```

Builds a string from Unicode code points, or `:Err(:BadUtf32)` for a number that is not one (a
surrogate, a negative number, or one above 1114111) and for zero.
