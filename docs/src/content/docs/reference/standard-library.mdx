ry ships a small standard library modeled on Roc's builtins: `Result`, `List`, `Str`, `Num`, `Dict`
and `Set`. Every function is fully typed, never meets `NA`, and reports failure as a tag instead of
an error or a warning, so the pieces compose with [`match`](/type-checking/records-and-tags/) and
the checker follows every step:

```r
parse_ids <- function(text: character) -> Result<list[integer], :InvalidNumStr> {
  parts <- List.map(Str.split_on(text, ","), Str.trim)
  List.map_try(parts, Str.to_integer)
}

counts: Dict<character, integer> <- List.walk(list("a", "b", "a"), Dict.empty(), function(seen, word) {
  Dict.update(seen, word, function(found) :Ok(Result.with_default(found, 0L) + 1L))
})

List.sum(parse_ids("3, 1, 2"))
```

`parse_ids("3, 1, 2")` is `:Ok(list(3L, 1L, 2L))`, `parse_ids("3, x")` is `:Err(:InvalidNumStr)`,
and `counts` is `Dict.from_list(list(("a", 2L), ("b", 1L)))`. The last line is the mistake the
checker catches: the result has to be unwrapped, with `match` or `Result.with_default`, before its
list can be summed.

The library runs only on ry's runtime, so run such a script with `ry run --runtime ry`. GNU R does
not have these functions, and a script that calls one fails there with "could not find function".

## Conventions

These rules hold in every module:

- **Names are plain R names.** `List.map` is one symbol, called like any R function; there is no
  method syntax and no `ry::` prefix. The names live in an environment called `package:ry`, which
  sits on the search path just above `package:base`, so a definition of your own, or one from an
  attached package, comes first.
- **A collection is an R list.** `List.map` takes any list and returns a new one, and
  `Str.split_on` returns a list of strings. `List.from_vector` turns an atomic vector into a list,
  and `List.to_vector` turns a list of scalars back.
- **Positions are 1-based** `integer`s, as in `xs[[1L]]`. A whole double such as `2` is accepted
  too.
- **A string is a length-one `character`, and a number a length-one `integer` or `double`.** `NA`
  and `NaN` are refused with an error, because no function has an `NA` case to fall into.
- **Misuse is an error, not a tag.** An argument of the wrong type, an `NA`, or an `integer`
  `List.sum` or `List.product` that overflows stops with an R error that names the problem.
- **Failure is a tag.** A function that can fail returns `:Ok(value)` or `:Err(tag)`, typed
  `Result<T, E>`, and the tag names the reason: `:OutOfBounds`, `:NotFound`, `:ListWasEmpty`,
  `:KeyNotFound`, `:InvalidNumStr`, `:BadUtf8`, `:Overflow`, `:DivByZero`, `:SqrtOfNegative` or
  `:LogNeedsPositive`.
- **Equality is `identical()`**, wherever a function compares values (`List.contains`,
  `Dict.keep_shared`).
- **Orderings are tags.** `Num.compare` returns `:LT`, `:EQ` or `:GT`, and `List.sort_with` takes a
  function that does the same.
- **Every value is immutable.** A function that "changes" a list, dictionary or set returns a new
  one.

A function that gets the wrong kind of value stops with an error that names the parameter:

```text
Error in List.len(c(1, 2)) :
  `list` must be a list, not a double vector of length 2
```

## Dictionaries and sets

R has no dictionary or set with value semantics, so `Dict` and `Set` are values of their own, like
ry's records and tags. `typeof()` is `"dict"` or `"set"`, and the class is `ry_dict` or `ry_set`.
Both keep insertion order, print as the call that rebuilds them, and compare with `identical()`
regardless of order:

```r
d <- Dict.from_list(list(("b", 2), ("a", 1)))
d
#> Dict.from_list(list(("b", 2), ("a", 1)))
identical(d, Dict.from_list(list(("a", 1), ("b", 2))))
#> [1] TRUE
```

A key or element is a `logical`, `integer`, `double` or `character` scalar that is not `NA` or
`NaN`. Every key of one collection has the same type, which the checker enforces. At run time
integers and doubles mix, as in R's own `==`: `1L` and `1` are the same key, and the keys become
doubles. `-0` and `0` are the same key too. `identical()` still tells an integer-keyed collection
from a double-keyed one, as it tells `1L` from `1`.

`length()`, `identical()`, `all.equal()`, `format()`, `deparse()` and `as.list()` understand them.
Any other R function refuses one, before it runs and in the checker, so convert with `as.list()`,
which gives a list of `(key, value)` tuples or of elements:

```text
Error in sum(d) :
  `d` is a ry dict, not an R object; convert it with `as.list()`
```

## Limits

- **Updates copy.** `Dict.insert`, `Set.insert` and `List.append` build a new value, so a loop that
  grows a collection one entry at a time takes time quadratic in its size. Build from a list with
  `Dict.from_list`, `Set.from_list` or `List.map` instead.
- **`Result.and_then` keeps one error type.** `f` must return the same error tag as the result it
  continues, so `Result.and_then(Str.to_integer(s), function(n) :Err(:NotPositive))` is a
  `type-mismatch`: the checker does not widen the error to `:InvalidNumStr | :NotPositive`.
- **A lookup with a key of another type finds nothing.** `Dict.get(d, 1L)` on a dictionary with
  `character` keys is `:Err(:KeyNotFound)` at run time; the checker reports it as a
  `type-mismatch` before that.

### Result

A result is `:Ok(value)` or `:Err(error)`, typed `Result<T, E>`. The alias is built in, so every annotation can use it.

#### `Result.is_ok`

```
<T, E> fn(result: Result<T, E>) -> logical
```

Whether the result is `:Ok`.

```r
Result.is_ok(:Ok(1L))
#> TRUE
```

#### `Result.is_err`

```
<T, E> fn(result: Result<T, E>) -> logical
```

Whether the result is `:Err`.

```r
Result.is_err(:Ok(1L))
#> FALSE
```

#### `Result.with_default`

```
<T, E> fn(result: Result<T, E>, default: T) -> T
```

The `:Ok` value, or `default` for an `:Err`.

```r
Result.with_default(:Err(:Missing), 0L)
#> 0L
```

#### `Result.map`

```
<A, B, E> fn(result: Result<A, E>, f: fn(A) -> B) -> Result<B, E>
```

Applies `f` to an `:Ok` value and leaves an `:Err` alone.

```r
Result.map(:Ok(2L), function(x) x * 10L)
#> :Ok(20L)
```

#### `Result.map_err`

```
<T, A, B> fn(result: Result<T, A>, f: fn(A) -> B) -> Result<T, B>
```

Applies `f` to an `:Err` value and leaves an `:Ok` alone.

```r
Result.map_err(:Err("disk full"), function(e) :IoError(e))
#> :Err(:IoError("disk full"))
```

#### `Result.map_both`

```
<A, B, C, D> fn(result: Result<A, B>, on_ok: fn(A) -> C, on_err: fn(B) -> D) -> Result<C, D>
```

Applies `on_ok` to an `:Ok` value or `on_err` to an `:Err` value.

```r
Result.map_both(:Err(404L), function(x) x, function(code) Str.concat("HTTP ", Num.to_str(code)))
#> :Err("HTTP 404")
```

#### `Result.and_then`

```
<A, B, E> fn(result: Result<A, E>, f: fn(A) -> Result<B, E>) -> Result<B, E>
```

Chains a step that can fail: `f` gets the `:Ok` value and returns the next result.

```r
Result.and_then(Str.to_integer("42"), function(n) if (n > 0L) :Ok(n) else :Err(:InvalidNumStr))
#> :Ok(42L)
```

#### `Result.on_err`

```
<T, A, B> fn(result: Result<T, A>, f: fn(A) -> Result<T, B>) -> Result<T, B>
```

Recovers from an `:Err`: `f` gets the error and returns the next result.

```r
Result.on_err(Str.to_integer("x"), function(e) :Ok(0L))
#> :Ok(0L)
```

### Str

Functions over single strings. Patterns and separators are matched literally, never as regular expressions.

#### `Str.is_empty`


### Dict

A dictionary maps keys to values, typed `Dict<K, V>`. See [Dictionaries and sets](#dictionaries-and-sets) for the rules on keys.

#### `Dict.empty`

```
<K: key, V> fn() -> Dict<K, V>
```

A dictionary with no entries.

```r
Dict.empty()
#> Dict.empty()
```

#### `Dict.single`

```
<K: key, V> fn(key: K, value: V) -> Dict<K, V>
```

A dictionary with one entry.

```r
Dict.single("a", 1)
#> Dict.from_list(list(("a", 1)))
```

#### `Dict.from_list`

```
<K: key, V> fn(pairs: list[tuple{K, V}]) -> Dict<K, V>
```

A dictionary from `(key, value)` tuples; a later tuple replaces an earlier one with the same key.

```r
Dict.from_list(list(("a", 1), ("b", 2), ("a", 3)))
#> Dict.from_list(list(("a", 3), ("b", 2)))
```

#### `Dict.to_list`

```
<K: key, V> fn(dict: Dict<K, V>) -> list[tuple{K, V}]
```

The entries as `(key, value)` tuples, in insertion order.

```r
Dict.to_list(Dict.from_list(list(("a", 1), ("b", 2))))
#> list(("a", 1), ("b", 2))
```

#### `Dict.len`

```
<K: key, V> fn(dict: Dict<K, V>) -> integer
```

The number of entries.

```r
Dict.len(Dict.single("a", 1))
#> 1L
```

#### `Dict.is_empty`

```
<K: key, V> fn(dict: Dict<K, V>) -> logical
```

Whether the dictionary has no entries.

```r
Dict.is_empty(Dict.empty())
#> TRUE
```

#### `Dict.get`

```
<K: key, V> fn(dict: Dict<K, V>, key: K) -> Result<V, :KeyNotFound>
```

The value for `key`, or `:Err(:KeyNotFound)`.

```r
Dict.get(Dict.single("a", 1), "a")
#> :Ok(1)
```

#### `Dict.contains`

```
<K: key, V> fn(dict: Dict<K, V>, key: K) -> logical
```

Whether the dictionary has an entry for `key`.

```r
Dict.contains(Dict.single("a", 1), "b")
#> FALSE
```

#### `Dict.insert`

```
<K: key, V> fn(dict: Dict<K, V>, key: K, value: V) -> Dict<K, V>
```

Adds an entry, or replaces the value of an existing key in place.

```r
Dict.insert(Dict.single("a", 1), "b", 2)
#> Dict.from_list(list(("a", 1), ("b", 2)))
```

#### `Dict.remove`

```
<K: key, V> fn(dict: Dict<K, V>, key: K) -> Dict<K, V>
```

Removes the entry for `key`, if there is one.

```r
Dict.remove(Dict.from_list(list(("a", 1), ("b", 2))), "a")
#> Dict.from_list(list(("b", 2)))
```

#### `Dict.update`

```
<K: key, V> fn(dict: Dict<K, V>, key: K, f: fn(Result<V, :Missing>) -> Result<V, :Missing>) -> Dict<K, V>
```

Sets the entry for `key` from `f`, which gets `:Ok(value)` or `:Err(:Missing)` and returns either; `:Err` removes the entry.

```r
Dict.update(Dict.single("hits", 1L), "hits", function(r) :Ok(Result.with_default(r, 0L) + 1L))
#> Dict.from_list(list(("hits", 2L)))
```

#### `Dict.keys`

```
<K: key, V> fn(dict: Dict<K, V>) -> list[K]
```

The keys, in insertion order.

```r
Dict.keys(Dict.from_list(list(("a", 1), ("b", 2))))
#> list("a", "b")
```

#### `Dict.values`

```
<K: key, V> fn(dict: Dict<K, V>) -> list[V]
```

The values, in insertion order.

```r
Dict.values(Dict.from_list(list(("a", 1), ("b", 2))))
#> list(1, 2)
```

#### `Dict.walk`

```
<K: key, V, S> fn(dict: Dict<K, V>, state: S, f: fn(S, K, V) -> S) -> S
```

Folds over the entries: `f` gets the state, a key and its value.

```r
Dict.walk(Dict.from_list(list(("a", 1), ("b", 2))), 0, function(total, k, v) total + v)
#> 3
```

#### `Dict.map`

```
<K: key, A, B> fn(dict: Dict<K, A>, f: fn(K, A) -> B) -> Dict<K, B>
```

Replaces every value with `f` of its key and value.

```r
Dict.map(Dict.from_list(list(("a", 1), ("b", 2))), function(k, v) v * 10)
#> Dict.from_list(list(("a", 10), ("b", 20)))
```

#### `Dict.keep_if`

```
<K: key, V> fn(dict: Dict<K, V>, predicate: fn(K, V) -> logical) -> Dict<K, V>
```

The entries for which `predicate` of the key and value is `TRUE`.

```r
Dict.keep_if(Dict.from_list(list(("a", 1), ("b", 2))), function(k, v) v > 1)
#> Dict.from_list(list(("b", 2)))
```

#### `Dict.drop_if`

```
<K: key, V> fn(dict: Dict<K, V>, predicate: fn(K, V) -> logical) -> Dict<K, V>
```

The entries for which `predicate` is `FALSE`.

```r
Dict.drop_if(Dict.from_list(list(("a", 1), ("b", 2))), function(k, v) v > 1)
#> Dict.from_list(list(("a", 1)))
```

#### `Dict.insert_all`

```
<K: key, V> fn(first: Dict<K, V>, second: Dict<K, V>) -> Dict<K, V>
```

The entries of both; where a key is in both, `second`'s value wins.

```r
Dict.insert_all(Dict.single("a", 1), Dict.from_list(list(("a", 5), ("b", 2))))
#> Dict.from_list(list(("a", 5), ("b", 2)))
```

#### `Dict.keep_shared`

```
<K: key, V> fn(first: Dict<K, V>, second: Dict<K, V>) -> Dict<K, V>
```

The entries of `first` whose key and value are both in `second`.

```r
Dict.keep_shared(Dict.from_list(list(("a", 1), ("b", 2))), Dict.from_list(list(("a", 1), ("b", 0))))
#> Dict.from_list(list(("a", 1)))
```

#### `Dict.remove_all`

```
<K: key, V> fn(first: Dict<K, V>, second: Dict<K, V>) -> Dict<K, V>
```

The entries of `first` whose key is not in `second`.

```r
Dict.remove_all(Dict.from_list(list(("a", 1), ("b", 2))), Dict.single("a", 0))
#> Dict.from_list(list(("b", 2)))
```
